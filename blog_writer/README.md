# 블로그 작업기 (초안 — 로그인까지)

네이버 블로그 자동 작성기의 바탕. 지금은 **로그인까지만** 한다.

계정·비밀번호·IP 를 이 프로그램이 들고 있지 않다. **찍고(zzikko)가 정본**이고 받아다 쓴다.

```
찍고 어드민                        이 프로그램
  블로그 프로필  (IP ↔ 크롬 프로필)  ──▶  프로필마다 크롬을 띄우고
  네이버 계정    (아이디·비번)       ──▶  아이디마다 로그인
                                   ◀──  결과 보고 (실패한 아이디는 내려간다)
```

## 구조

| 파일 | 하는 일 |
|---|---|
| `config.py` | 설정 읽기, 프로필·계정 자료 모양, 폴더 경로 규칙 |
| `zzikko.py` | 찍고 어드민 API (로그인 · 프로필 받기 · 결과 보고) |
| `browser.py` | 프로필 폴더 + 그 프로필의 IP 로 크롬 띄우기 |
| `naver_login.py` | 네이버 로그인 (기존 `n_blog_writer` 코드를 옮겨 왔다) |
| `vpn.py` | VPN 자리 바꾸기 (설정에 명령을 넣었을 때만) |
| `run_login.py` | 위를 엮어 전부 돌린다 |

## 준비 (처음 한 번)

```
cd C:\project\cluade\py\blog_writer
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m playwright install chromium
copy settings.sample.json settings.json
```

`settings.json` 에 **운영진 계정**과 찍고 주소를 적는다.

`settings.json` 과 `profiles/` 는 git 에 올라가지 않는다 (`.gitignore`).

## 찍고 쪽 준비

1. 어드민 → **블로그 프로필** 에서 프로필을 만든다 (이름은 `prof-01` 처럼 영문·숫자 — 폴더 이름이 된다).
   - **보여야 할 IP** 는 비워 둔다. 첫 작업 때 작업기가 재서 적어 넣는다.
   - **프록시 주소**는 VPN 업체가 준 중계 주소를 적는 칸이다. VPN 프로그램을 쓰면 **비운다**.
   - **VPN 위치 이름**은 자동 전환에 쓴다 (`Korea #5` 처럼 VPN 에서 고르는 이름).
2. 어드민 → **네이버 계정** 에서 각 계정의 **블로그 프로필** 칸에 그 이름을 적는다 (보통 셋).
3. 어드민 → **블로그 프로필** 에서 이번에 쓸 아이디를 **라디오로 하나** 고른다.
   골라 두면 그 아이디 하나만 돌린다. 안 고르면 붙은 것 전부를 돈다.
   같은 라디오를 다시 누르면 풀린다.

## 실행

`.venv` 의 파이썬으로 돌린다 (시스템 파이썬에는 playwright 가 없다).

```
.venv\Scripts\python.exe run_login.py              # 프로필 전부
.venv\Scripts\python.exe run_login.py prof-01      # 그 프로필만
```

옵션 두 가지.

| 옵션 | |
|---|---|
| `--shot` | 성공했을 때도 화면을 `shots/` 에 남긴다 |
| `--keep` | 작업이 끝나도 **창을 닫지 않고** Ctrl+C 를 누를 때까지 기다린다 |

`--keep` 은 화면을 눈으로 들여다볼 때 쓴다. Ctrl+C 를 누르면 그 창을 닫고 다음 계정으로 간다.
(`headless` 가 true 면 창이 안 뜨므로 쓸 수 없다 — 프로그램이 알려주고 멈춘다.)

IP 가 제대로 물렸는지만 보고 싶으면:

```
.venv\Scripts\python.exe -c "import run_login; run_login.check_ip('prof-01')"
```

## IP 를 어떻게 다루나

IP 를 쓰는 길이 두 가지다.

| | 어떻게 | 프로필에 |
|---|---|---|
| **VPN 프로그램** | PC 전체가 그 IP 로 나간다 | 프록시 칸을 **비운다** |
| **프록시** | 브라우저만 중계 서버를 거친다 | 프록시 주소·포트를 적는다 |

어느 쪽이든 **작업 전에 실제 IP 를 재서 `보여야 할 IP` 와 맞는지 본다.**

```
프로그램 시작
  브라우저로 지금 IP 를 잰다 (파이썬이 아니라 브라우저로 — 네이버가 보는 게 그것이다)
  기대 IP 가 비어 있으면 -> 지금 IP 를 그 프로필의 것으로 기록
  기대 IP 와 다르면      -> 로그인하지 않고 멈춘다
  맞으면                 -> 그 프로필의 아이디를 차례로 로그인
                            아이디마다 IP 를 다시 잰다 (도중에 VPN 이 끊길 수 있다)
  끝나면                 -> "다음은 prof-02 입니다. VPN 을 바꾸고 Enter"
```

⚠️ **IP 가 맞지 않으면 절대 로그인하지 않는다.** 엉뚱한 IP 로 한 번 로그인하면
그 계정이 그 IP 에 묶여 버린다. 틀린 채로 도는 것보다 멈추는 게 낫다.

## VPN 자동 전환 (쓸 수 있으면)

`settings.json` 의 `vpn_command` 를 채우면 프로필마다 알아서 VPN 을 옮긴다.
`{location}` 자리에 그 프로필의 **VPN 위치 이름**이 들어간다.

```json
"vpn_command": "nordvpn.exe -c -n \"{location}\"",
"vpn_wait_seconds": 8
```

비워 두면 사람이 직접 바꾸고 Enter 를 누르는 방식으로 돈다.

⚠️ **이 명령은 찍고가 아니라 이 PC 의 설정 파일에 둔다.** 서버가 내려준 문자열을 그대로
실행하면, 어드민 계정이 하나 뚫렸을 때 사무실 PC 에서 아무 명령이나 돌릴 수 있는 길이 된다.
찍고는 **자리 이름이라는 데이터만** 주고, 무엇을 실행할지는 이 PC 가 정한다.

## 로그인은 진짜 마우스로 한다

Playwright 의 click·type 은 브라우저가 만들어 내는 가짜 사건이다. 커서가 순간이동하고
글자 간격이 고르다. 실제로 보호조치에 걸린 뒤로 **운영체제의 진짜 마우스·키보드**로 바꿨다
(`human.py`).

    로그인 페이지로 이동
    창을 맨 앞으로, 1~2초 쉼 (소수점)
    아이디 칸으로 마우스를 부드럽게 이동 (0.45~1.15초, 가감속)
    칸 안쪽 아무 데나 클릭 (늘 정가운데를 누르지 않게)
    붙여넣기
    1~2초 쉼
    비밀번호 칸도 같은 방식
    1~2초 쉼
    로그인 버튼도 마우스로

⚠️ **돌아가는 동안 PC 를 쓰면 안 된다.** 마우스가 진짜로 움직이므로 그 사이에 다른 창을
누르면 클릭이 엉뚱한 곳에 꽂힌다.
⚠️ 급하면 **마우스를 화면 왼쪽 위 모서리로 밀어라.** pyautogui 가 즉시 중단시킨다(FAILSAFE).
⚠️ 좌표는 `(창 위치 + 주소창 높이 + 페이지 안 좌표) × 화면 배율` 로 계산한다.
**배율(devicePixelRatio)을 빼먹으면 125% 화면에서 전부 어긋난다.**

마우스를 쓰지 못하는 상황(창이 가려짐, 좌표가 화면 밖)이면 평범한 클릭으로 돌아간다.

## 보호조치에 걸리면

캡차와 다르다. **계정이 이미 찍혔다는 뜻이다.** 프로그램이 구분해서 알려준다.
풀고 나서 그 아이디는 하루쯤 쉬게 두는 편이 낫다 — 바로 또 돌리면 더 세게 걸린다.

가장 큰 방아쇠는 타이핑 방식이 아니라 **처음 보는 기기 + 처음 보는 IP** 다.
본 아이디는 프로필을 한 번 만들어 두고 그 조합(프로필 폴더 + IP)을 계속 쓰는 게 중요하다.

## 막혔을 때 — 화면 사진

로그인이 성공하지 못하면 그 순간의 창을 `shots/` 에 사진으로 남긴다. 캡차인지,
기기 등록인지, 비밀번호 오류인지는 글자만으로는 구분이 안 되기 때문이다.
파일 이름은 `1125-113412-아이디-need_human.png` 꼴이고, 저장한 경로를 화면에도 찍어 준다.

성공했을 때도 남기려면 `--shot` 을 붙인다.

```
.venv\Scripts\python.exe run_login.py prof-01 --shot
```

⚠️ **로그인된 화면이 그대로 찍힌다.** `shots/` 는 git 에 올라가지 않는다. 이 PC 에만 둔다.

## 알아 둘 것

- **크롬 프로필 폴더는 아이디마다 따로다** (`profiles/prof-01/blogid1`). IP 는 프로필 단위로 같이 쓴다.
  한 폴더에 아이디 셋을 몰면 네이버가 브라우저당 한 계정만 받으므로 돌릴 때마다
  로그아웃→로그인을 반복하게 되는데, 그게 세션을 유지하는 것보다 훨씬 눈에 띈다.
- **두 번째 실행부터는 로그인을 아예 안 한다.** 폴더에 쿠키가 남아 있다.
- ⚠️ **캡차·기기 등록·2단계 인증은 프로그램이 풀지 않는다.** 뜨면 창을 열어 둔 채 멈추고
  사람을 부른다. 자동으로 뚫으려 들면 계정이 더 빨리 막힌다.
- 아이디·비밀번호가 틀렸을 때만 '실패'로 보고한다 — 그 계정은 찍고에서 **쓸 수 없음**으로
  내려가 다음 실행에서 빠진다. 되살리는 건 사람이 어드민에서 한다.
- 같은 IP 에서 계정을 연달아 로그인하지 않는다 (8~20초 사이를 둔다).
- 같은 폴더를 두 번 동시에 열면 크롬이 폴더를 잠가 두 번째가 죽는다. 한 번에 하나씩 돌린다.
- 윈도우 콘솔은 cp949 라 `—` 같은 글자가 출력에 섞이면 터진다. 화면에 찍는 문구에는
  쓰지 않고, 출력을 파일로 넘길 때를 대비해 `run_login.py` 가 stdout 을 utf-8 로 돌려 둔다.
